# Мастер-план: «Дорогами славы» — навигатор по местам воинской славы Мостовского района

Создан 2026-09-19. Проект-близнец `projects/school/mostovsky-churches/`: та же
архитектура и дисциплина фактов, другой контент. Роль агента: full-stack
исполнитель школьного веб-проекта (research + frontend, без Node.js-сборщиков,
без внешних CDN).

## Что именно сдаём

Районный молодёжный интернет-конкурс «Патриоты в сети», номинация
«патриотический цифровой контент» (стикерпаки, игры, **цифровые навигаторы по
историческим местам воинской славы**). Сдача: работа размещена на открытой
странице в соцсети (ссылка на GitHub Pages), заявка — на почту райисполкома
(действие владельца).

## Решения (зафиксированы в интервью с владельцем, 2026-09-19)

| # | Решение |
|---|---|
| D1 | Формат: только навигатор, без викторины и стикерпака |
| D2 | Охват: Мостовский район, первое кольцо — 12 точек (весь существенный пул ~40 объектов районной базы — в research-заметках) |
| D3 | Карта: SVG-схема района на реальной геометрии OSM (не тайловая интерактивная карта) |
| D4 | Стек: чистые HTML/CSS/JS, без сборщиков и CDN, работает офлайн с флешки |
| D5 | Публикация: GitHub Pages через subtree push (паттерн из `projects/README.md`), только по явной команде владельца |
| D6 | Ресерч контента — агент (база районной библиотеки, savehistory.by, райисполком), владелец валидирует и добавляет местные детали |
| D7 | Фото: только с атрибуцией (Commons или личные); до полевой поездки фото-слоты честно пустые |
| D8 | Расхождения источников (число погибших в Княжеводцах: 600 на постаменте vs 970 в прессе) приводятся честно, на странице места |
| D9 | Название проекта: «Дорогами славы»; каталог `glory-navigator` |

## Архитектура

Как в проекте храмов: одностраничник + `data.js` (единый источник данных с
проверками целостности при загрузке), роутинг `#/slug`, без сборщиков и без
внешних CDN. Единый условный знак — звезда (`js/glory-icon.js`), одна и та же
на схеме, в легенде и в списках. Единственный писатель `#app` — `js/dom.js`.

```
├── index.html          ← приложение: пять отделов + страницы мест
├── about.html          ← «О проекте», задание и источники (статичный)
├── css/style.css       ← дизайн-токены (мемориальная палитра, не церковная)
├── js/data.js          ← ВСЕ данные, тексты и правила целостности
├── js/router.js        ← разбор адреса, порядок маршрута, поиск по slug
├── js/glory-icon.js    ← единый условный знак: звезда (SVG)
├── js/dom.js           ← строители разметки; единственный писатель #app
├── js/map-geometry.js  ← реальная геометрия OSM (из проекта храмов, переиспользована)
├── js/map.js           ← SVG-схема: звёзды, нитка, легенда
├── js/sections.js      ← пять отделов
├── js/place.js         ← страница места, фото-слоты, 404
├── js/app.js           ← диспетчер: адрес → отдел или страница места
├── tests/              ← контракты без фреймворка
└── MASTER-PLAN.md      ← этот файл
```

## Что НЕ делаем

- Викторины, стикерпаки, игры (D1)
- Тайловую интерактивную карту (D3)
- Node-сборщики, CDN, фреймворки (D4)
- Пуш и Pages без явного разрешения владельца (D5)

## Известные хвосты

- Координаты 10 из 12 точек — центры населённых пунктов (`exactAddr: false`),
  уточняются через OSM Nominatim / при полевой поездке.
- Фото Commons для сельских братских могил почти наверняка нет — слоты пустые
  до поездки (D7).
- Числа расхождения в Княжеводцах (600/900/970) — помечены на странице места (D8).
